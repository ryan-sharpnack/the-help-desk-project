# Homelab Showcases

This folder contains write-ups of contributors' homelabs: the personal environments they use to practice and develop real IT skills.

A homelab showcase doesn't need expensive hardware. A single laptop running virtual machines counts. What matters is what you built, why, and what you learned.

## What to include

| Section | What to cover |
|---|---|
| Overview | What your homelab is and why you built it |
| Hardware | Physical machines, networking gear, and storage |
| Virtualization | Hypervisor and virtual machines or containers |
| Operating systems | Windows, Linux, and versions used |
| Network | Topology, segmentation, DNS, DHCP, and so on |
| Services | Active Directory, file shares, monitoring, automation, etc. |
| Projects | What you've built or configured in the lab |
| Skills developed | What you've learned and what you're working on next |

Diagrams and screenshots are encouraged. Place them in an `images/` folder next to your write-up and link to them.

## How to submit a showcase

1. Create a new file named `yourusername-lab-name.md`, for example `jsmith-windows-domain-lab.md`.
2. Fill in the sections above. You can skip any that don't apply.
3. Open a Pull Request. See [CONTRIBUTING.md](../CONTRIBUTING.md) for the full workflow.

## Before you submit

- Remove passwords, keys, and other secrets.
- Blur or replace public IP addresses, domain names, and anything that identifies your home network.
- Don't include proprietary software, license keys, or employer-owned material.

## Want feedback?

Share your lab in the **Homelab Showcase** category in [Discussions](https://github.com/ryan-sharpnack/the-help-desk-project/discussions) to get input from other members, or ask for mentorship there.
