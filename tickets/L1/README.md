# Level 1 (L1) — Foundational IT Support

## Overview

Level 1 focuses on developing foundational IT Support competencies through practical troubleshooting exercises based on common end-user computing incidents.

These scenarios are designed to develop the technical knowledge, diagnostic methodology, problem-solving abilities, documentation practices, and communication skills expected of an entry-level IT Support professional.

Each ticket provides an opportunity to investigate a reported issue, identify its underlying cause, implement an appropriate resolution, and verify the outcome.

## Learning Objectives

Through these exercises, participants will develop the ability to:

- Diagnose common Windows workstation and application issues.
- Troubleshoot user authentication and profile problems.
- Identify basic network connectivity and DNS resolution issues.
- Understand file access, permissions, and storage-related problems.
- Investigate application and service failures.
- Apply systematic troubleshooting methodologies.
- Document technical findings, resolutions, and verification results.
- Recognize when an issue requires escalation.

## Completion Standards

Each ticket should be completed using the standardized [TEMPLATE.md](TEMPLATE.md).

A completed ticket should document:

1. Incident description and business impact.
2. Environment and initial observations.
3. Troubleshooting methodology and diagnostic evidence.
4. Root cause analysis.
5. Resolution and implementation.
6. Verification and testing.
7. User communication and incident closure.
8. Lessons learned and escalation considerations.

Technical exercises should clearly distinguish between incidents successfully reproduced in a homelab, researched scenarios, and authorized real-world experiences.

## Expected Outcome

Upon completing Level 1, participants should have developed a foundational understanding of common IT Support incidents and demonstrated their ability to approach troubleshooting systematically, document technical work, and resolve appropriate entry-level support issues.

**Don't just learn IT. Practice IT. Prove it.**
