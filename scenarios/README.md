# Real-World IT Scenarios

This folder contains realistic IT support scenarios contributed by industry professionals, experienced technicians, and hiring managers.

A scenario describes a problem the way it would arrive at a help desk. Aspiring professionals can reproduce it in their own environments, troubleshoot it, and document their resolution as a ticket in [tickets](../tickets/).

## Scenarios vs. tickets

| | Scenario | Ticket |
|---|---|---|
| Written by | Industry professionals and hiring managers | Contributors working in their own labs |
| Describes | A problem to be solved | A problem that was solved |
| Used for | Practice exercises | Showing the troubleshooting process |

## What to include

- **Title:** a short description of the issue
- **Difficulty:** Beginner, Intermediate, or Advanced
- **Category:** networking, Windows, Linux, hardware, and so on
- **The report:** what the user says is wrong, in their own words
- **Environment:** the systems and technologies involved
- **How to reproduce:** how someone can recreate the problem in a lab
- **Skills practiced:** what a learner will develop by solving it
- **Success criteria:** how a learner knows the problem is resolved
- **Hints (optional):** nudges for people who get stuck

Describing the real root cause is optional. Some contributors prefer to leave it out so learners can discover it.

## How to submit a scenario

1. Create a new file named `short-descriptive-name.md`, for example `user-cannot-access-shared-drive.md`.
2. Fill in the items above.
3. Open a Pull Request. See [CONTRIBUTING.md](../CONTRIBUTING.md) for the full workflow.

## Confidentiality

Please don't submit anything that could expose your employer or anyone else. That includes:

- Company names, internal system names, and proprietary documentation
- Real usernames, customer details, or other personally identifiable information
- Credentials, tokens, or internal network details

Generalize or rewrite real incidents so they reflect the type of problem without identifying where it happened. If you aren't sure whether you're allowed to share something, check with your employer first.

Want to talk through an idea before writing it up? Use the **Industry Insights** category in [Discussions](https://github.com/ryan-sharpnack/the-help-desk-project/discussions).
