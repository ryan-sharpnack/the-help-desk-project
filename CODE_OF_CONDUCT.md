# Code of Conduct

## Our Commitment

The Help Desk Project is committed to providing an open, welcoming, inclusive, and professional environment for everyone participating in our community.

We believe knowledge sharing, collaboration, and mutual respect are essential to developing the next generation of IT professionals.

Regardless of your technical experience, educational background, or professional status, you are welcome here.

## Expected Behavior

All community members are expected to:

- Treat others with respect, professionalism, and courtesy.
- Welcome contributors regardless of their experience level.
- Provide constructive and technically meaningful feedback.
- Encourage questions and knowledge sharing.
- Respect differing opinions and technical approaches.
- Give appropriate credit to original contributors.
- Help maintain a collaborative learning environment.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, discrimination, intimidation, or personal attacks.
- Insulting or ridiculing someone for their technical experience or knowledge.
- Deliberately discouraging others from participating.
- Publishing private or confidential information without permission.
- Trolling, disruptive behavior, or repeated bad-faith contributions.
- Spam, malicious submissions, or intentionally misleading technical documentation.
- Any conduct that undermines the safety and integrity of the community.

## Technical Disagreements

Technical disagreements are welcome.

There are often multiple ways to troubleshoot and resolve an IT problem. Contributors are encouraged to challenge assumptions, suggest alternatives, and explain different approaches.

However, disagreements must remain professional and focused on the technical subject matter.

Critique the solution, not the individual.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the severity and circumstances of a violation, maintainers may:

1. Issue a warning.
2. Remove inappropriate content.
3. Temporarily restrict participation.
4. Remove a contributor from the community.
5. Report serious violations to GitHub when appropriate.

Maintainers reserve the right to take reasonable action to protect the community.

## Reporting Violations

The Help Desk Project is currently establishing a private reporting channel for Code of Conduct concerns.

Until a private reporting method is available, please do not post sensitive personal information, private communications, or detailed allegations in public GitHub Issues or Discussions.

If you encounter behavior that violates this Code of Conduct, please avoid engaging in hostile exchanges. The project will update this section once a private reporting channel has been established.

For security vulnerabilities, please refer to GitHub's Private Vulnerability Reporting feature. Security vulnerabilities should not be reported publicly.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues.
- GitHub Discussions.
- Pull Requests.
- Repository contributions.
- Other community spaces officially associated with The Help Desk Project.

## Our Goal

We want to build a community where aspiring IT professionals can learn, experienced professionals can mentor, and industry leaders can help shape the technical capabilities of tomorrow's workforce.

Everyone has something to contribute.

**Let's build each other up.**
